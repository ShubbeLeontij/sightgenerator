Установка
---------

Есть два способа установки, первый проще, а второй даёт большую свободу кастомизации (если не хватает того, что предлагает оконное приложение, можно попробовать поредактировать файл defaults.py или другие программные файлы), но требует от пользователя базовых умений работы с терминалом для установки.
1) Папка с exe файлом\
Скачайте [zip архив](https://github.com/ShubbeLeontij/sightgenerator/releases/download/5.0/sightgenerator.zip) \
Ничего дополнительно скачивать не надо, однако при первом запуске возможна реакция антивируса - разрешите ему запуск файла.

2) Питоновский проект\
Склонируйте [проект](https://github.com/ShubbeLeontij/sightgenerator), скачайте и установите [python3](https://www.python.org/downloads/) (если он не был установлен ранее), убедитесь, что галочки `ADD Python to PATH` и `td/tk and IDLE` поставлены. 
Установите необходимые библиотеки `python -m pip install -r requirements.txt`.
В папке проекта необходимо запустить `ui.py`.

Настройки
---------

В меню настроек присутствует множество параметров, большинство пояснены всплывающими подсказками. 
Если же всё равно непонятно, за что отвечает данная настройка, есть PREVIEW (ПРЕДПРОСМОТР), примерно показывающий у чему приведут изменения.

Левая часть меню - глобальные настройки, применяющиеся на все прицелы.
Правая же часть отдельна для каждого типа прицелов - их переключение осуществляется с помощью меню в правом верхнем углу.
Прицелы генерируются трёх типов, выбираемых по начальной скорости снаряда: simulator_s (медленные, менее 600 м/с), simulator (обычные, 600-1100 м/с) и simulator_f (быстрые, более 1100 м/с).
Во всех учитывается параллакс, а отличаются они в основном дистанциями, для которых нарисованы метки - чем медленнее снаряд, тем плотнее метки.
Кроме них каждый танк получает прицелы arcade и realistic, построенные по его standard-снаряду: в этих режимах параллакса нет, поэтому прицел стоит на стволе и сведение не учитывается, а аркадный от реалистичного отличается только отсутствием дальномера.
Они тоже бывают трёх скоростных вариантов (arcade_s/arcade/arcade_f и realistic_s/realistic/realistic_f в settings.json), выбираемых по тем же порогам скорости.
Наконец, танк с лазерным дальномером получает ещё один прицел - simulator_laser. Такой танк меряет дистанцию в игре, а баллистический вычислитель сам наводит орудие, поэтому в этом прицеле нет ни стадиометрического дальномера, ни дальних меток дистанции - только метки параллакса на ближних дистанциях.

Для симуляторных прицелов или если Вы просто хотите использовать круги вместо стандартных меток есть меню EDIT SIM CIRCLES (РЕДАКТИРОВАТЬ КРУГИ) - в нём каждая строчка создаёт метку дистанции используя круг.

После изменения настроек не забудьте нажать SAVE SETTINGS AND EXIT TO MAIN MENU (СОХРАНИТЬ НАСТРОЙКИ И ВЫЙТИ В ГЛАВНОЕ МЕНЮ), простое же закрытие окна отменит все изменения.

Если Вы хотите узнать какие прицелы получит танк, можете открыть data.json - файл, по которому строятся прицелы. Каждый ключ верхнего уровня - unit_id танка.
Внутри него "zoom" - зум прицела наводчика без приближения, "convergence" - сведение в метрах (дистанция нулевого параллакса, null означает отсутствие сведения), "coords" - высота/боковое смещение прицела относительно ствола в метрах, "standard" - снаряд, чей прицел привязывается к танку в global.blk, "laser" - есть ли у танка лазерный дальномер.
Каждый остальной ключ - это снаряд танка, для каждого создаётся отдельный прицел с именем этого снаряда, а для standard-снаряда ещё и arcade.blk с realistic.blk, и simulator_laser.blk если "laser" равен true. Внутри снаряда лежат "speed" в м/с (по ней выбирается тип прицела), игровой "type" снаряда, а также "mass", "caliber" и "cx", которые пока не используются.
Пустой объект `{}` означает, что для этого танка прицел не генерируется, а снаряды без "speed" (ПТУР и НУР) пропускаются.

Конфигурации
-------

В проекте присутствует поддержка конфигураций, созданных во внутриигровом меню редактирования прицелов.
Выбрать сохранённую конфигурацию можно с помощью кнопки в меню настроек - при запуске она применится на танках, где не было выбрано других прицелов с конфигурациями.
Таким образом при входе в игру все прицелы будут выбраны, заходить во внутриигровое меню нужно только если нужен другой прицел.

Это реализуется путём редактирования файла global.blk, привязанного к вашему аккаунту.
Он лежит по пути ~/.config/WarThunder/Saves/account-id/production/ для Linux и MacOS или Documents/My Games/WarThunder/Saves/account-id/production/ для Windows.
Вы можете узнать свой ID на https://store.gaijin.net/user.php.
Также во избежание случайных изменений и багов со стороны данного проекта рекомендуется перед запуском программы сделать бэкап global.blk (а лучше всей папки Saves).

Для очистки привязки конфигураций прицелов используйте кнопку Очистить Привязку прицелов в главном меню.

Запуск
------

В главном меню все прицелы создаются всегда, а переключатели выбирают только тот, который записывается в global.blk как прицел по умолчанию: arcade, realistic или simulator - лазерный прицел танка, если у него есть лазерный дальномер, иначе прицел его standard-снаряда.
Для создания прицелов нажмите кнопку RUN (ЗАПУСК) или Enter на клавиатуре.
